# Pedacinho do Céu - Sistema de Gestão Escolar

Este repositório contém o núcleo de processamento do sistema de gestão escolar, focado em automação financeira e acadêmica.

## 🚀 Como Compilar
Para compilar o projeto principal:
\`\`\`bash
make
\`\`\`
O executável será gerado em \`./bin/programa.exe\`.

## 🧪 Testes
Para rodar os testes unitários (TDD):
\`\`\`bash
make test
./bin/testeRegressivo.exe
\`\`\`

## 📂 Estrutura
- `src/`: Código fonte.
- `include/`: Cabeçalhos (.hpp).
- `bin/`: Executáveis e binários (ignorado pelo git).
- `test/`: Testes funcionais.
